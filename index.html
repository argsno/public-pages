02这个仓库怎么用

结构约定

  • index.html — 本目录页
  • <主题>/index.html — 单篇内容页，自包含（CSS/JS 内联，不依赖外部 CDN）
  • assets/ — 需要跨页复用的图片等静态资源
  • .nojekyll — 关闭 Jekyll 处理，避免下划线开头的文件被忽略

发布方式

  • GitHub Pages，从 main 分支根目录构建
  • 推送后约 1 分钟自动生效
  • 默认地址 /<目录名>/，适合直接分享链接
  • 页面应自适应手机宽度，首屏先给结论
